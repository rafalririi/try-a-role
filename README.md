# Try a Role: Stop the Attack

A cybersecurity awareness game for King Abdulaziz University students. Play three cyber jobs and stop a real kind of attack in each one.

| Role | Attack | Habit |
|------|--------|-------|
| SOC Analyst | Ransomware | Update your devices |
| Phishing Investigator | Phishing & SMS | Check the sender and the link before you click |
| Social Engineering Defender | Fake IT support call | Never share an OTP code |

**Play:** open `index.html` in any browser, or use the GitHub Pages link of this repository.

CPCS 463 · Cybersecurity Awareness Activity · Rafal & Sedra

All companies, people and messages in the scenarios are fictional. Report suspicious messages at KAU to cybersecurity@kau.edu.sa.
